# Chroniques des Âges

**Valsane Studio**

Base multi-livres. Le rendu et le fonctionnement du Livre 01 sont calés sur la version de référence `La-Grotte-de-Valombre-25092026.zip` (V68.173).

## Formats
- JPG/JPEG : illustrations, portraits, présentation, objets, textures.
- PNG : uniquement lorsqu’une transparence est nécessaire (icônes notamment).

## Livre 01
Les illustrations de pages doivent être ajoutées manuellement dans :
`books/Livre01-La-Grotte-de-Valombre/images/`

Nommage : `La-Grotte-de-Valombre-001.jpg`, etc.
